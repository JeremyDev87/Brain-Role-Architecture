# Prior-art boundary

The project studied the conceptual sketch at
[AetherReverie/brain-architecture exact commit](https://github.com/AetherReverie/brain-architecture/tree/dd2c094b0790b5cb4358c8d02d66ee6b517201e8).
It preserves the benefits of a low-cognitive-load, file-oriented model but does not copy its template.
Brain-Role adds a normative contract, schemas, deterministic validation, explicit roles, threat modeling,
public/private enforcement, conformance fixtures, versioning, and package verification.
